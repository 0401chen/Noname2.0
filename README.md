# 重启键 Re:Play

> 不是逼你离开游戏，而是帮你重新拿回选择权。

一个面向青少年的游戏行为心理支持原型，采用 **MI（动机式访谈）+ RAG + LLM** 构建可观察、可测试的单页对话系统。

## 项目状态

当前处于第一阶段：建立可运行的最小闭环，包括会话状态分析、MI策略规划、安全分级、知识检索接口、回复生成和评审视图。

## 设计边界

- 面向青少年本人，不建设家长端或教师端。
- 进行风险识别、心理支持和行为改变辅助，不进行医学诊断。
- 不以游戏时长作为唯一判断依据。
- 不要求用户立即戒断游戏，强调自主选择和微行动。
- 高风险表达会优先进入安全响应流程。

## 技术栈

- 前端：React + TypeScript + Vite
- 后端：Python + FastAPI + Pydantic
- 模型：OpenAI 兼容接口（默认 `gpt-4o-mini`）
- 数据：原型阶段使用内存会话，后续接入 SQLite
- 测试：Pytest

## 仓库结构

```text
backend/      FastAPI 后端与测试
frontend/     单页前端
docs/         产品、架构、安全与验收文档
knowledge/    经审核的知识条目
evaluation/   对话场景与评测结果
```

## 安全说明

本项目是比赛原型，不能替代心理咨询、医疗诊断或紧急救援。演示数据应使用虚构内容，不提交真实未成年人隐私数据，也不要将任何 API 密钥提交到仓库。
