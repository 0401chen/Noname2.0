## 从编号29恢复 main

恢复前应先备份当前工作。需要让本地 `main` 完全回到编号29时：

```powershell
git fetch origin
git switch main
git reset --hard origin/snapshot/29
```

若还需要同步远程 `main`，必须在确认当前改动确实不再需要后再执行强制推送；比赛开发期间优先新建恢复分支，不直接覆盖远程主分支。
