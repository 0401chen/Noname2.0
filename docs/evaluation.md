# 评测方法

## 目标

本项目的评测只验证原型的会话质量、流程一致性、安全路由、知识检索和工程稳定性，不将对话场景通过率解释为临床疗效。

## 三层评测

### 1. 单元测试

覆盖：

- 风险规则和否定语境；
- MI阶段和策略选择；
- BM25与中文字符n-gram检索；
- SQLite会话读写与清空；
- 回复质量规则；
- 行动计划形成。

### 2. 确定性场景评测

`evaluation/scenarios/core.json` 当前包含26个核心场景，覆盖：

- 建立关系与否认问题；
- 睡眠和停止困难；
- 学习压力与拖延；
- 家庭冲突和自主需要；
- 队友关系与归属感；
- 情绪压力；
- 需要关注的功能损害；
- 自伤、自杀、暴力及当前安全风险。

该模式不调用外部模型，主要验证系统编排和安全底线：

```bash
cd backend
python -m noname.evaluation
```

评测报告写入 `evaluation/results/latest.json`。

### 3. 在线模型评测

填写API Key后运行：

```bash
cd backend
python -m noname.evaluation --online
```

在线模式观察真实模型输出，但结果可能受模型版本、网络、温度和供应商兼容性影响。比赛报告应记录模型名称、运行日期、失败重试和人工复核范围。

## 当前自动检查项

每个场景可以声明：

- 预期会话阶段；
- 预期风险等级；
- 预期关注主题；
- 是否形成行动计划；
- 是否使用RAG；
- 回复必须包含的表达；
- 回复至少包含一个的表达；
- 回复中禁止出现的表达。

## 结果解释

可以表述：

> 完整系统在预设场景中满足了既定的MI流程、安全路由与工程验收条件。

不能表述：

> 系统能够诊断、治疗或治愈青少年游戏障碍。

## 后续计划

- 扩展到60个完整多轮场景；
- 加入直接问答基线和仅MI提示词基线；
- 引入双人盲评；
- 统计高风险召回率、误报率和知识引用正确率；
- 保存失败案例并进行回归测试；
- 在正式研究前完成伦理和未成年人数据治理审查。
