# 品牌与表达规范

## 1. 对外名称

最终比赛版的主产品名称统一使用：

> **Noname助手**

当前 `Final-version` 前端顶部仍保留 `Re:Play` 作为小型次级副标识，因此在界面截图、演示视频或浏览器标题中可能同时看到：

> **Noname助手 · Re:Play**

材料中建议始终以“Noname助手”为主名称，`Re:Play` 只作为副品牌或视觉标识，不与主产品名并列成两个独立产品。

## 2. 核心表达

> 不是逼你离开游戏，而是帮你重新拿回选择权。

这句话体现产品的核心立场：

- 不直接把游戏视为问题本身；
- 不通过说教或强迫要求用户戒断；
- 先理解游戏给用户带来的价值；
- 再帮助用户识别自己不喜欢的影响；
- 改变目标与行动方式由用户自己决定。

## 3. 产品定位表述

推荐：

> Noname助手是一个面向青少年的游戏行为智能支持系统，通过动机式访谈风格的状态化多轮会话、按需知识检索、长期会话记忆和安全机制，帮助用户理解游戏背后的需要、识别现实影响，并在愿意改变时形成可执行的小行动实验。

不推荐：

- “戒网瘾AI”；
- “治疗游戏成瘾系统”；
- “青少年心理医生”；
- “自动诊断游戏障碍”；
- “自主制定戒游戏方案”。

## 4. 语言风格

系统应尽量：

- 使用青少年容易理解的自然中文；
- 先回应用户当前表达，再决定是否提问；
- 避免连续追问“意义、价值、最满足什么”；
- 避免训诫口吻；
- 避免“你必须”“你应该立刻戒掉”等强迫表达；
- 不制造 AI 依赖；
- 不声称能够保密、现实救援或替代专业支持。

## 5. 对规划功能的表述

推荐：

> 用户自主驱动的微行动实验规划与调整机制。

或：

> 基于 MI 阶段与用户行动意图的结构化微行动规划模块。

不推荐：

> 通用自主规划引擎。

因为当前系统主要面向游戏行为支持领域，依据用户行动表达、会话主题和预设领域结构形成单个微行动实验，并不承担复杂多任务分解和长期自主执行。

## 6. 对安全能力的表述

推荐：

> 系统采用规则风险扫描、LLM上下文理解和持久安全状态机组成的多层安全机制。高风险状态下暂停普通游戏建议，并由程序化条件控制退出。

不推荐：

> AI能够处理心理危机。

系统可以进行风险识别和安全优先引导，但不能替代现实中的紧急救援、临床判断或专业心理服务。

## 7. 比赛材料统一原则

技术方案、PPT、视频和README应统一使用以下关键词：

```text
理解：心理需要 / 主线锚点 / 长期记忆
决策：MI阶段 / 策略选择 / 按需RAG
行动：用户自主微实验 / 状态保存 / 后续调整
安全：规则检测 / 上下文理解 / 持久SAFETY状态
```

避免在不同材料中夸大尚未验证的能力，也避免把 `Re:Play` 描述成与 Noname助手平行的第二个产品。
