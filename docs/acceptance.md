# 第五阶段验收清单

状态说明：

- `[x]`：已有实现，并由当前本地冒烟测试或确定性测试覆盖；
- `[~]`：代码和测试已提交，等待最新CI或本地完整测试确认；
- `[ ]`：最终部署或人工研究阶段处理。

自动评测与冒烟测试只验证工程和预设对话表现，不代表临床疗效。

## 1. 本地可运行性

- [x] Conda Python 3.11环境可以安装根目录`requirements-dev.txt`；
- [x] 后端可以通过`uvicorn noname.main:app --reload`启动；
- [x] 前端可以通过`npm run dev`启动；
- [x] 前后端代理和`/api/chat`通信正常；
- [x] 有效API Key能够产生在线模型回复；
- [x] 页面名称显示为`Noname助手`；
- [x] 匿名会话可以一键重置；
- [~] `python -m noname.provider_check`能够返回模型、主机、兼容模式和耗时；
- [~] 空API Key仍可使用确定性降级流程。

## 2. 模型供应商兼容

- [~] 优先使用`response_format=json_object`；
- [~] 供应商不支持JSON模式时退回提示词JSON；
- [~] 供应商不支持`temperature`时使用默认采样参数；
- [~] 空choices、空content和非JSON输出安全降级；
- [~] 模型接口自检不输出API Key；
- [~] 测试套件不会读取本地真实API Key或调用真实供应商。

## 3. 会话质量

- [x] 首轮不直接要求用户戒游戏；
- [x] 回复先反映用户感受、价值或矛盾；
- [~] 每轮最多提出一个主要问题；
- [~] 区分改变语言和维持现状语言；
- [x] ENGAGE、FOCUS、EVOKE、PLAN、REVIEW状态可运行；
- [~] 单独输入`0—10`分时结合历史解释为改变意愿；
- [~] 低改变意愿优先使用自主支持，而不是推动计划；
- [x] 行动计划足够小、可观察，并允许失败后调整；
- [x] 睡眠场景能够形成三天行动卡。

## 4. 风险安全

- [x] 明确自伤、自杀或无法保证当前安全进入HIGH；
- [x] 高风险切换SAFETY并停止普通游戏建议；
- [~] 否定表达不会被简单规则当作肯定意图；
- [x] 高风险回复鼓励连接现实中的可信任成年人；
- [x] 不生成未经核验的热线号码；
- [x] 模型不能降低规则层风险；
- [~] 回复审核阻止诊断、强迫、依赖诱导和虚假救援承诺；
- [~] 回复审核阻止欺骗监护人、伪造记录、隐藏通宵和内部提示泄露；
- [~] 过长回复和多问题回复自动替换为安全降级回复。
